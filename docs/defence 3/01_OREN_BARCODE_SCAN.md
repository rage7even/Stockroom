# Орен · Barcode Scan целиком

**Твоя зона защиты** — схема и генерация штрихкода, Django endpoint, построение этикетки, камера и резервный декодер в Angular, ручной и USB-ввод, поиск товара и подсчёт строки поставки.

## Что показать на экране

1. В **Products** найди `DEM-C35W-WHT` и открой карточку товара. Покажи текстовый код **`SR-DEM-C35W-WHT`**, полосы Code 128 и кнопку **Print label**. Один код относится к одному SKU, поэтому несколько одинаковых единиц используют одну этикетку.
2. Закрой карточку и нажми **Scan barcode**. На подготовленном HTTPS-адресе наведи камеру на этикетку. Для показа без оборудования введи код в поле **Barcode** и нажми **Find product**. Должна открыться та же карточка.
3. При необходимости покажи неизвестный код `SR-UNKNOWN`. В **Network** ищи `GET /api/products/barcode?code=SR-UNKNOWN`, ответ **404**. Для правильного кода ответ **200**, в JSON проверь `sku`, `barcode` и `product_name`.
4. Перейди в **Purchase receiving**, выбери учебный заказ и повтори скан. В строке товара теперь **Receive now = 1**, остальные строки сохраняют свои значения. На этом шаге передай слово Аксункару, который подтвердит приёмку.

## Что сказать

> Я отвечаю за Barcode Scan полностью, от базы данных до интерфейса. SQLite вычисляет уникальный код из SKU. Angular строит этикетку Code 128, а камера или ввод возвращают её текст. UI отправляет текст в Django, Django находит товар и возвращает SKU. На странице приёмки тот же SKU определяет строку, в которой мы считаем единицы. Склад обновляется, когда сотрудник нажимает Confirm receipt и сервер сохраняет приёмку.

| Вопрос | Ответ |
| --- | --- |
| Почему один код на несколько единиц? | SKU описывает вид товара. Количество одинаковых экземпляров хранится отдельно. |
| Что, если товар существует, но его нет в заказе? | Поиск товара может пройти успешно. Форма приёмки проверяет строки выбранного заказа и покажет ошибку. |
| Зачем checksum? | При чтении он помогает отсеять ошибочно распознанную последовательность полос. |
| Отправляются ли кадры камеры на сервер? | Кадры обрабатываются в браузере. На сервер отправляется текст штрихкода для поиска SKU. |
| Почему камера недоступна с телефона? | На телефоне для показа используем HTTPS и разрешаем доступ к камере. При недоступной камере остаётся поле **Barcode**. |

**Передача слова.** «Мы получили товар и посчитали одну единицу в форме. Аксункар покажет, как подтверждение меняет остаток и как сервер защищает приёмку от повторного запроса».
