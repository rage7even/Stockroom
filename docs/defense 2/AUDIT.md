## Где проверка требует продолжения

- Первый запуск исходного `qa/http_check.py` на Windows дал p95 0,0843 с и ответы 201/409, затем завершился с `WinError 32` при удалении временного `server.log`. Скрипт также выводит старую дату и Linux из текста файла. Для повторной проверки перенаправлен вывод сервера и актуализированы подписи в памяти, исходный файл в проекте не правился.
- На реальном телефоне и с адреса развёртывания ещё нужен полный прогон. На узком экране доступный остаток в таблице Products может быть за пределами начальной видимой области. Карточка показывает его сразу. Стоит проверить, удобно ли сотруднику находить его с телефона.
- Запуск команд `setup.bat` и `start.bat`, круглосуточное выполнение расписания, оборудование и полный ручной чек-лист в этом прогоне не проверялись. Прогон Angular и HTTP выполнен прямыми командами.
