# Защита 2 · речь и действия команды

Для текущей Docker-версии используйте [самостоятельные выступления участников](00_ORDER.md). Ниже сохранён запасной сценарий по базовым операциям склада на исходной демобазе.

**Время на основной показ — около 8 минут.** Откройте этот файл на втором экране. Текст в кавычках можно говорить своими словами. Говорите «я реализовал» и «я проверил» только о том, что вы действительно сделали.

## За 15 минут до защиты

1. В WSL из папки `Stockroom_Study` запустите уже собранный Docker-образ. Откройте сайт из Windows и войдите как Manager через кнопку **Manager** в блоке **Explore the demo**, затем **Sign in**.

   ```bash
   docker compose up -d --no-build
   docker compose ps
   ```

   Адрес — [http://127.0.0.1:8001](http://127.0.0.1:8001). Если образ нужно пересобрать, запустите `docker compose up -d --build` заранее. [Инструкция запуска](../RUN_LOCAL.md)

2. Проверьте исходные числа. **Products → Search products → `BAS-C65W-WHT` → карточка товара**. Для сценария нужны **10 On shelf, 6 Reserved, 4 Available**. На репетиции в конце отмените созданный заказ, чтобы отпустить резерв.
3. Если Docker временно недоступен или числа в его базе уже отличаются, запустите приложение в WSL на отдельной свежей копии учебной базы. Команды ниже предполагают, что `python3 stockroom.py setup` уже выполнен.

   ```bash
   stockroom_demo="$(mktemp -d)"
   cp database/demo.db "$stockroom_demo/stockroom.db"
   STOCKROOM_DB="$stockroom_demo/stockroom.db" python3 stockroom.py run --port 8002
   ```

   Тогда вся команда показывает сайт на **8002**, а Аксункар и Орен используют одну и ту же учебную базу. Для ручного снимка на этом сервере откройте второй терминал, подставьте путь из первого и выполните `STOCKROOM_DB="/путь/к/stockroom.db" ./.venv-linux/bin/python backend/manage.py maintenance --force-backup`. Чтобы узнать путь в первом терминале, выполните `printf '%s\n' "$stockroom_demo/stockroom.db"` до запуска сервера.

4. Откройте вкладки **Products**, **Orders**, **Stock history**, терминал Акылбека и терминал Диаса. Нурдаулет открывает проверенный адрес на телефоне. Адрес `127.0.0.1` с телефона указывает на сам телефон. Если доступного с телефона адреса ещё нет, откройте DevTools на ноутбуке, нажмите **Toggle device toolbar** и выставьте ширину **390 px**. На показе назовите это эмуляцией экрана телефона.

## 0:00–1:20 · Нурдаулет — вход и мобильный сайт

**Что сказать.** «Stockroom помогает сотрудникам склада видеть, сколько товара есть и сколько можно пообещать магазину. Покажу, как сотрудник находит нужный товар на узком экране».

**Что сделать.** Покажи вход и открытие бокового меню. Выбери **Products**, введи `BAS-C65W-WHT` в поиск и открой карточку **GaN 65W Fast Charger** нажатием на название. Покажи **On shelf**, **Reserved** и **Available**. Если смотришь таблицу на телефоне, коротко покажи прокрутку внутри неё и открой карточку, где все три числа видны вместе.

**Передача слова.** «На полке десять зарядок, из них шесть уже обещаны магазинам. Аксункар покажет, как сервер проверяет оставшиеся четыре».

## 1:20–3:15 · Аксункар — заказ и резерв

**Что сказать.** «Сотрудник собирает позиции в форме. В момент подтверждения сервер проверяет все позиции по актуальным остаткам. Если хотя бы одной позиции не хватает, резерв по заказу не создаётся».

1. Открой **Orders → Create order**. В **Customer** выбери **Almaty Mobile**. В **Sales channel** оставь **Phone / sales manager**. В **Product** выбери **GaN 65W Fast Charger**, в **Quantity** введи **5**. Нажми **Confirm & reserve stock**. Покажи сообщение, что доступно только четыре.
2. В той же форме измени количество на **4** и нажми **Confirm & reserve stock**. Запиши номер нового заказа из списка. Открой **Products** и покажи для того же SKU **10 On shelf, 10 Reserved, 0 Available**.
3. Если показываете снимок до отмены, сейчас дай Орену запустить команду бэкапа и дождись сообщения **Backup created**. Затем открой новый заказ по номеру → **Cancel order** и подтверди отмену. Покажи статус **Cancelled**, вернись в **Products** и покажи **4 Available**.

**Передача слова.** «Мы отменили заказ, поэтому резерв освободился. Акылбек покажет, откуда берутся эти числа в базе».

## 3:15–4:35 · Акылбек — данные и SQL

**Что сказать.** «SKU идентифицирует товар. Позиция заказа связывает заказ с товаром и хранит количество. SQL суммирует только активные резервы и вычитает их из остатка на полке».

**Что запустить.** В терминале WSL из корня проекта выполни команду. Она читает учебную `database/demo.db` и выводит результаты первого запроса из `queries.sql`.

```bash
python3 - <<'PY'
import sqlite3
from pathlib import Path

sql = Path("database/queries.sql").read_text(encoding="utf-8").split(";", 1)[0]
with sqlite3.connect("file:database/demo.db?mode=ro", uri=True) as db:
    print("Products:", db.execute("SELECT COUNT(*) FROM product").fetchone()[0])
    print("SKU | Product | On shelf | Reserved | Available")
    for row in db.execute(sql):
        print(*row, sep=" | ")
PY
```

**Что показать.** В стартовой демобазе **18 товаров**. В выводе найди `BAS-C65W-WHT` со значениями **10 | 6 | 4**. Объясни, что запрос ищет товары ниже порога пополнения. Если спросят про ограничения, приведи пример: SKU — первичный ключ, а один SKU может встречаться в одном заказе только один раз.

**Передача слова.** «Эти правила можно проверить и при ошибке внутри операции. Диас покажет такой тест».

## 4:35–5:55 · Диас — проверка сбоя

**Что сказать.** «Проверю случай, когда во время подтверждения заказа не удаётся записать историю. Тест специально вызывает этот сбой и проверяет, что заказ, резерв и остаток не изменились».

**Что запустить.** В WSL из корня проекта:

```bash
./.venv-linux/bin/python backend/manage.py test \
  inventory.tests.StockroomTests.test_07_audit_failure_rolls_back --noinput -v 2
```

**Что показать.** В выводе найди имя теста и **OK**. Если спрашивают про полный прогон, открой [отчёт](AUDIT.md). В нём отдельно зафиксированы 15 автотестов, HTTP-проверка и мобильная эмуляция. Один тест проверяет 20 вариантов входных данных.

**Передача слова.** «Тест показал, что при сбое изменения откатываются. Орен покажет, как сохраняется копия всей базы».

## 5:55–7:20 · Орен — Docker и бэкап

**Что сказать.** «Docker Compose запускает Stockroom с готовой сборкой интерфейса. SQLite и снимки лежат в постоянном томе, поэтому данные сохраняются при замене контейнера. Сам снимок создаёт Stockroom».

**Что показать.** В терминале WSL из корня проекта:

```bash
docker compose ps
docker compose exec -T stockroom ls -lh /data/backups
```

Покажи контейнер и файл снимка. Если снимок сделали перед отменой заказа, покажи его имя. Для этого в части Аксункара, пока заказ ещё **Confirmed**, запусти:

```bash
docker compose exec -T stockroom python backend/manage.py maintenance --force-backup
```

Для самостоятельного показа Орена используй [полный сценарий восстановления](BACKUP_DEMO.md). Там Орен создаёт свой заказ, выгружает снимок под коротким именем и сравнивает статус одного заказа на 8001 и 8002. Если основной показ идёт через Python, покажи снимок той же базы и отдельно объясни, как запускается Docker-версия.

## 7:20–8:00 · Заключение

«Мы показали один складской сценарий целиком: сотрудник проверяет товар, сервер принимает заказ только при наличии, отмена освобождает резерв, а бэкап сохраняет состояние базы. Дальше мы добавляем сохранённые черновики, CSV, профиль, заявки и возвраты».

## Что вставить в речь, когда новые функции готовы

Добавляйте эти шаги после репетиции на той версии, которую будете показывать. Названия новых кнопок и экранов замените на фактические.

| Кто | Что сказать и показать | Что должно получиться |
| --- | --- | --- |
| Нурдаулет | «Покажу, как сотрудник меняет имя с телефона». Открыть сайт на реальном телефоне, изменить своё имя, сохранить, обновить страницу. | Имя сохранилось и видно в меню, роль прежняя. |
| Аксункар | «Заказ можно отложить и продолжить позже». Собрать A, создать B, обновить страницу, выйти и войти тем же сотрудником, открыть A. Подтвердить A один раз. | A и B раздельны. A сохранил позиции. Резерв появился при подтверждении. |
| Акылбек | «Импорт добавляет строки каталога и сообщает, где ошибка». Импортировать заранее проверенный файл с новыми SKU, выгрузить каталог, затем открыть результат импорта файла с дубликатом. | Новые SKU видны в каталоге и экспорте. Для дубликата есть понятная ошибка. |
| Диас | «Сотрудник видит, что происходит с его заявкой». В одном окне сотрудник создаёт заявку. В другом Диас меняет статус. В первом обновить список и показать тот же номер. | Статус изменился у того же номера. Другой сотрудник не видит чужую заявку. |
| Орен | «Магазин вернул пять зарядок: три можно снова продать, две учитываем как брак». Открыть заранее подготовленный отгруженный заказ, оформить возврат **3 исправных + 2 бракованных** с причиной и комментарием. Показать остаток и историю. Затем попробовать превысить оставшийся лимит возврата. | Доступный остаток увеличился на 3, брак на 2. Причина и комментарий сохранены. Отклонённая попытка не меняет остатки. |

Для новой версии основным показом Орена сделайте возврат. На Docker и бэкап оставьте короткий показ по времени или ответ на вопрос.
