# Орен · возврат от магазина, Docker и бэкап

## Что показать

1. В обычном окне войди как **Shop (Sales)**. В **Orders** открой отгруженный заказ **Demo Mobile Week 11** по номеру из команды `seed_week11`. Если возврат по этому заказу уже сделан, заранее создай как Manager новый заказ на пять доступных единиц для этого магазина и нажми **Ship order → Confirm action**.
2. В **Store returns** выбери товар, введи **Sellable 3**, **Defective 2**, причину и комментарий. Нажми **Send return request**. Покажи **Pending**. На этом шаге запас ещё прежний.
3. В приватном окне войди как **Manager**, открой тот же заказ и нажми **Receive return**. Покажи **Received**, затем в **Products** открой карточку товара. От исходных значений **Available** вырос на 3, **Defective returns** вырос на 2.
4. Если успеваешь, попробуй отправить ещё одну единицу из того же отгруженного заказа на пять. Сервер отклонит превышение лимита.
5. Для короткого показа Docker запусти `docker compose ps`. Для полноценного показа бэкапа и восстановления используй [свой отдельный заказ и сценарий 8001/8002](BACKUP_DEMO.md).

## Что сказать

«Магазин отправляет заявку по своему отгруженному заказу и добавляет причину и комментарий. Склад принимает товар и подтверждает возврат. Из пяти зарядок три снова можно продать, две отражаются в учёте брака. Docker запускает проект, а постоянный том хранит SQLite и её снимки».

## Какой код открыть

- [orders.ts](../../frontend/src/app/orders.ts) — `submitReturn` отправляет форму магазина, `reviewReturn` передаёт решение склада.
- [week11.py](../../backend/inventory/week11.py) — `returns` проверяет магазин, отгрузку и лимит, `review_return` меняет остаток при приёмке и защищает от повторного начисления.
- [models.py](../../backend/inventory/models.py) — `StockReturn` хранит количества, причину, комментарий и статус.
- [compose.yaml](../../compose.yaml) — порт сайта и том `/data`. [maintenance.py](../../backend/inventory/management/commands/maintenance.py) создаёт и проверяет снимок. [restore.py](../../integration/restore.py) восстанавливает его.
