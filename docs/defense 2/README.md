# Stockroom — защита 2, неделя 11

План на 13 ноября 2026 с уточнениями команды. Черновики, CSV, профиль, заявки и возвраты доступны в локальной Docker-версии. Для защиты начните с [показа функций 11-й недели](WEEK11_DEMO.md). Доступ с реального телефона нужно проверить отдельно.

| Участник | Что записано в плане на скриншоте | Как команда уточнила задачу |
| --- | --- | --- |
| Аксункар · 24B031908 | Backend, «card» и другая бизнес-логика | «Card» означает cart, корзину заказа. Аксункар ведёт корзину и правила заказа, включая сохранение нескольких черновиков сотрудника. |
| Акылбек · 24B032013 | Import/export CSV, update data, «intex contrains» | Ведёт импорт и экспорт CSV целиком, включая серверную обработку. Добавляет новые записи в базу, проверяет индексы и ограничения. |
| Нурдаулет · 24B031742 | Frontend, edit profile, deploy, mobile app | Ведёт редактирование профиля и развёртывание интерфейса. На защите показывает адаптивный сайт в браузере телефона. |
| Диас · 24B032021 | Report issue page, status, test new functions | Самостоятельно делает интерфейс, API, хранение и статусы заявок. После интеграции сам повторно проверяет весь проект и пишет новые тесты. |
| Орен · 24B031750 | Docker, брак, feedback, возврат, backup | Ведёт возвраты целиком, включая форму, API, серверные правила и хранение данных. Feedback — причина возврата и комментарий. Для локального показа доступны Docker Compose и резервное копирование. |

## Согласованные сценарии

1. Преподавательнице показываем сайт в браузере телефона.
2. Сотрудник может сохранить заказ как черновик, начать другой и потом вернуться к первому. Черновики доступны после обновления страницы и повторного входа в тот же аккаунт. Резерв появляется при подтверждении.

Предлагаемые границы первой версии — импорт и экспорт каталога товаров, возврат по отгруженному заказу, просмотр своих заявок сотрудником и смена статуса Диасом. Детали приёмки есть в карточках участников.

Предыдущий сценарий защиты находится в [defence](../defence/00_ORDER.md).
