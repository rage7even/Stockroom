# Stockroom · показ функций 11-й недели

## Запуск

Из папки проекта в WSL:

```bash
docker compose up -d --no-build
docker compose exec -T stockroom python backend/manage.py seed_week11 --catalogue
```

Откройте [Stockroom](http://127.0.0.1:8001). Для запуска без Docker сначала обновите базу командой `python3 stockroom.py setup`, затем выполните `./.venv-linux/bin/python backend/manage.py seed_week11 --catalogue` и `python3 stockroom.py run`.

Команда `seed_week11` добавляет три товара, магазин **Demo Mobile Week 11**, отгруженный заказ на пять зарядок `DEM-C35W-WHT` и два аккаунта для показа. Кнопка **Shop (Sales)** входит как `shop@stockroom.local`, а **Tech Support** — как `support@stockroom.local`. Команда печатает номер заказа. При повторном запуске ранее добавленные записи остаются на месте. Для повторного показа возврата после исчерпания лимита оформите и отгрузите новый учебный заказ для этого магазина.

## Показы по очереди

[Подробный порядок с репликами и ссылками на код для каждого](00_ORDER.md).

Флаг `--catalogue` добавляет 100 учебных товаров с SKU от `LAB-D001-STD` до `LAB-D100-STD`. Существующие товары и их остатки сохраняются при повторном запуске.

| Участник | Действия | Результат |
| --- | --- | --- |
| Аксункар | **Orders → Create order**, выбрать магазин и товар, ввести заметку A, дождаться **Draft saved**. Через **Save draft** закрыть форму, собрать B, выйти и войти тем же сотрудником. Открыть A через **Continue**, подтвердить. | A и B хранятся отдельно. При подтверждении A резервируется его товар, B остаётся черновиком. |
| Акылбек | Как Manager открыть **Products → Import CSV** и выбрать [учебный CSV](../../database/week11-catalog.csv). Найти два новых SKU с префиксом CSV, нажать **Export CSV** и повторить импорт того же файла. | Каталог выгружается в UTF-8, повторный импорт отклоняет дубликат. Миграция также добавляет индекс для поиска заказов по статусу и дате. |
| Нурдаулет | Открыть сайт в браузере телефона, войти, открыть **Edit profile**, загрузить фото и заполнить имя, телефон и должность. Сохранить и обновить страницу. | Фото и поля сохраняются. Для реального телефона нужен доступный ему адрес. |
| Диас | В окне Sales открыть **Report issue**, отправить заявку и записать номер. В отдельном приватном окне войти как **Tech Support**, открыть **Issue queue** и сменить статус. Вернуться к Sales и обновить страницу. | Автор видит тот же номер с новым статусом. Tech Support имеет доступ к очереди, заявкам и своему профилю. |
| Орен | Войти как **Shop (Sales)**, открыть отгруженный заказ своего магазина, указать **Sellable 3**, **Defective 2**, причину и комментарий, нажать **Send return request**. В отдельном окне войти как **Manager**, открыть этот заказ и нажать **Receive return**. | Заявка сначала **Pending**, остаток прежний. После приёмки она **Received**, доступный остаток вырос на 3, **Defective returns** увеличился на 2. Попытка вернуть ещё единицу сверх отгрузки отклоняется. [Сценарий бэкапа](BACKUP_DEMO.md) |

## Проверка с телефона

Для временного показа на доверенной локальной сети с доступным адресом можно указать адрес ноутбука в `STOCKROOM_EXTRA_HOSTS` и запустить Compose с `STOCKROOM_BIND=0.0.0.0`. Телефон открывает адрес ноутбука с портом 8001. Доступность зависит от настроек сети Windows и WSL. На защите используйте заранее проверенный адрес. Стандартный запуск оставляет сайт доступным с ноутбука.

## Тесты

В WSL из корня проекта:

```bash
./.venv-linux/bin/python backend/manage.py test inventory --noinput
```

Проверки новых функций включают права, повторное подтверждение черновика, раздельный учёт исправных и бракованных товаров, лимит возврата, защиту роли профиля и атомарный импорт CSV.
