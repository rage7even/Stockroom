# Нурдаулет · интерфейс чата и восстановления · 24B031742

## Что показать

1. В сессии Manager откройте **Messages → Staff chat**. Найдите администратора по имени. Откройте диалог и отправьте «Заказ готов к передаче».
2. Во второй сессии откройте **Messages → Staff chat** под Admin, выберите Manager и ответьте. В первой сессии покажите автоматическое появление ответа. Для телефона удобно открыть второй аккаунт отдельно.
3. В сессии Manager откройте учебную закупку и нажмите **Open purchase chat**. Покажите, что чат открылся сразу для нужного `PO-…`. Во вкладке Supplier виден список его закупок.
4. На отдельном аккаунте введите неверный пароль и покажите сообщение. Откройте **Forgot password?**, запросите код на привязанный адрес, подтвердите новый пароль и войдите снова. Для локальной репетиции можно использовать тестовое письмо, сохранив исходные демоаккаунты для показа.

## Какой код открыть

| Файл и функция | Что объяснить |
| --- | --- |
| [purchase-chat.html](../../frontend/src/app/purchase-chat.html) · вкладки, список и форма | Показывает фильтр имени для сотрудников и фильтры поставщика и заказа для закупок. Если сервер отклоняет текст, поле сообщения остаётся доступным для исправления. |
| [purchase-chat.ts](../../frontend/src/app/purchase-chat.ts) · `switchMode()`, `loadList()`, `loadMessages()`, `send()` | URL хранит выбранный тип и собеседника. Компонент загружает новые сообщения раз в пять секунд. |
| [purchases.html](../../frontend/src/app/purchases.html) · **Open purchase chat** | Ссылка передаёт номер закупки. |
| [auth.html](../../frontend/src/app/auth.html), [auth.ts](../../frontend/src/app/auth.ts) · `submit()`, `requestCode()`, `resetPassword()` | Интерфейс показывает ошибку входа, затем проводит пользователя через почту, одноразовый код и подтверждение пароля. |

## Что сказать

«Оба вида переписки открываются из одного меню. Для сотрудников выбираем человека, для поставщика выбираем закупку. При ошибке сервер возвращает причину, а пользователь может исправить текст и отправить сообщение заново».

**Передача слова.** «Аксункар покажет, как сервер проверяет доступ к этим диалогам и отклоняет запрещённый текст».
