# Диас · фильтрация и QA · 24B032021

## Что показать

| Проверка | Действие | Ожидаемый результат |
| --- | --- | --- |
| Поиск закупок | В **Purchase chat** введите часть имени поставщика, затем добавьте номер `PO-…`. | Остаются только закупки, отвечающие обоим условиям. |
| Поиск сотрудника | В **Staff chat** введите часть имени администратора в другом регистре. | Список показывает совпадающие имена. |
| Фильтр текста | Попробуйте отправить `shiiiit` в обоих чатах. В одном из них повторите с `S.H.I.T!` и `merde`. | HTTP 400 и предупреждение. Текст остаётся в поле, в истории новой записи нет. |
| Исправленное сообщение | Замените отклонённый текст на `Delivery is ready.` и отправьте. | Сообщение записывается и появляется у обоих участников диалога. |
| Приватность | Откройте Staff chat под Sales и выберите Admin. | Видна только переписка Sales ↔ Admin, сообщения Manager ↔ Admin не появляются. |

## Какие тесты показать

- [test_staff_chat.py](../../backend/inventory/test_staff_chat.py) проверяет скрытие личных переписок, права внешних аккаунтов, фильтр имён и блокировку внесённых в словарь форм на 11 языках до записи в БД, включая растянутые буквы, разделители и типичные подмены символов.
- [test_week13.py](../../backend/inventory/test_week13.py) проверяет поиск закупок, видимость поставщика, сверку отгрузки и коды восстановления.
- [WEEK13_TEST_REPORT.md](../../qa/WEEK13_TEST_REPORT.md) содержит результаты Django и браузерных проверок.

```text
python backend/manage.py test inventory.test_staff_chat inventory.test_week13 --noinput
```
