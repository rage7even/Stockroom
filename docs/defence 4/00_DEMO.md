# Общий сценарий Defence 4

## Подготовка перед защитой

1. Соберите Angular и подготовьте учебную БД по [README](README.md). Возьмите номера `ORD-…` и `PO-…` из вывода `seed_week13`.
2. Откройте приложение в трёх отдельных сессиях: **Manager**, **Admin** и **Supplier**. Подготовьте карточки заказов, **Messages**, **Stock history**, терминал и вкладку **Network** в браузере.
3. Для показа сброса используйте отдельный аккаунт. Заранее проверьте почтовый backend. Для показа на телефоне подготовьте HTTPS и этикетки Code 128. Ручной ввод тех же кодов подходит для показа серверной сверки.
4. Перед выступлением проверьте, что заказ ещё `Confirmed` и счётчики начинаются с нуля. Для репетиции используйте отдельную учебную БД или создайте новый заказ с теми же позициями через **Orders**.

## Данные для показа

| Действие | Пример | Ожидаемый результат |
| --- | --- | --- |
| Чужой товар | `SR-DEM-PB10-GRY` | Заказ не меняется. |
| Сверка заказа | Два раза `SR-DEM-C35W-WHT`, один раз `SR-DEM-CBL2-BLK` | Счётчики `2 / 2` и `1 / 1`. |
| Личный чат | Manager: «Заказ готов, можешь подтвердить передачу?» Admin отвечает: «Да, передача подтверждена». | В обоих аккаунтах видны два сообщения в одном диалоге. |
| Чат закупки | Manager: «Подтвердите дату поставки». Supplier отвечает: «Поставка завтра утром». | Переписка привязана к номеру закупки. |
| Фильтр сообщений | Тестовое `shit` в обоих чатах, затем `Delivery is ready.` | Первые два запроса получают HTTP 400. Исправленный текст отправляется. |
